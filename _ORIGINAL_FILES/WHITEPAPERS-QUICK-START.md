# Whitepapers Import - Quick Start

## 🚀 5-Minute Import

### 0️⃣ Sync ACF Fields (30 sec)
```
Custom Fields → Sync available
Check "Whitepaper Fields (DEPRECATED)" → Sync
```

### 1️⃣ Download Images (1 min)
```bash
cd _ORIGINAL_FILES
./download-whitepaper-images.sh
```

### 2️⃣ Upload to WordPress Media (2 min)
```
Media → Add New
Upload all from whitepaper-images/ folder
```

### 3️⃣ Import Whitepapers (1 min)
```
Tools → Import → WordPress
Upload: wordpress-whitepapers-import.xml
Submit
```

### 4️⃣ Set Featured Images (1 min)
```
Edit each whitepaper post (7001-7028)
Set featured image from Media Library
```
