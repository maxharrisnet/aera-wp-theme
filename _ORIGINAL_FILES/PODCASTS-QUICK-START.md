# Podcasts Import - Quick Start

## 🚀 5-Minute Import

### 1️⃣ Download Images (1 min)
```bash
cd _ORIGINAL_FILES
./download-podcast-images.sh
```

### 2️⃣ Upload to WordPress Media (2 min)
```
Media → Add New
Upload all from podcast-images/ folder
```

### 3️⃣ Import Podcasts (1 min)
```
Tools → Import → WordPress
Upload: wordpress-podcasts-import.xml
Submit
```

### 4️⃣ Set Featured Images (1 min)
```
Edit each podcast post (5001-5015)
Set featured image from Media Library
```
