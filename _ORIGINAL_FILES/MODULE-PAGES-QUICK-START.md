# 🚀 Quick Start: Import Module Template Pages

## TL;DR - 4 Simple Steps

### 1️⃣ Download Images (16 featured images)
```bash
cd _ORIGINAL_FILES
bash download-module-images.sh
```

### 2️⃣ Import Pages to WordPress
1. WordPress Admin → **Tools** → **Import** → **WordPress**
2. Upload: `wordpress-module-pages-import.xml`
3. Assign to admin user
4. Submit

### 3️⃣ Upload Images to WordPress
1. WordPress Admin → **Media** → **Add New**
2. Upload all images from `_ORIGINAL_FILES/module-images/`

### 4️⃣ Link Images to Pages
1. Go to **Pages** in WordPress admin
2. Edit each module page (Aera Workspaces, Decision Engines, etc.)
3. Update `Platform Featured Image` ACF field
4. Select the corresponding image you uploaded
