# 🚀 Quick Start: Import Customer Data

## TL;DR - 4 Simple Steps

### 1️⃣ Download Images (Optional - you can also import first)
```bash
cd _ORIGINAL_FILES
bash download-customer-images.sh
```

### 2️⃣ Import Customer Posts
1. WordPress Admin → **Tools** → **Import** → **WordPress**
2. Upload: `wordpress-customers-import.xml`
3. Assign to admin user
4. Submit

### 3️⃣ Upload Images to WordPress
1. WordPress Admin → **Media** → **Add New**
2. Upload all images from `_ORIGINAL_FILES/customer-images/`

### 4️⃣ Link Images to Customer Posts
1. Go to **Customers** in WordPress admin
2. Edit each customer (BP-Castrol, PMI, AstraZeneca)
3. Update `Hero Image` and `Company Logo` ACF fields
4. Select the images you just uploaded

## ✅ What You'll Get

**3 Customer Posts:**
- BP-Castrol (Petrochemical)
- PMI (CPG)
- AstraZeneca (Pharmaceutical)

**Each with:**
- ✓ Card title
- ✓ Hero background image
- ✓ Company logo
- ✓ Industry type/tag
- ✓ 1-2 video asset links with CTAs
