# Videos Import - Quick Start

## 🚀 5-Minute Import

### 0️⃣ Sync ACF Fields (30 sec)
```
Custom Fields → Sync available
Check "Video Fields (DEPRECATED)" → Sync
```

### 1️⃣ Download Images (1 min)
```bash
cd _ORIGINAL_FILES
./download-video-images.sh
```

### 2️⃣ Upload to WordPress Media (2 min)
```
Media → Add New
Upload all from video-images/ folder
```

### 3️⃣ Import Videos (1 min)
```
Tools → Import → WordPress
Upload: wordpress-videos-import.xml
Submit
```

### 4️⃣ Set Featured Images (1 min)
```
Edit each video post (6001-6026)
Set featured image from Media Library
```
